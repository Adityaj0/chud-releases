# CHUD

**Get better at coding. Get ridiculously jacked.**

CHUD is a little pixel-art gym buddy that lives at the bottom of your Mac screen. Solve LeetCode problems and it grows from a skinny Noodle into the Final CHUD. When your friends solve something, their CHUD runs onto your screen to flex about it.

## Install (macOS 14+, Apple Silicon or Intel)

1. Download **CHUD-1.0.0.dmg** from [Releases](../../releases/latest).
2. Open it and drag **CHUD** into **Applications**.
3. Open CHUD. macOS warns that it's from an unidentified developer, because it isn't notarized by Apple. To allow it once:
   - **macOS 15 or later:** System Settings → Privacy & Security → scroll down → **Open Anyway**
   - **macOS 14:** right-click CHUD in Applications → **Open** → **Open**
   - or in Terminal: `xattr -dr com.apple.quarantine /Applications/CHUD.app`
4. Create an account, then add friends by username under **Dashboard → Friends**.

The first time anyone opens CHUD after a quiet stretch, the server takes up to a minute to wake up.
